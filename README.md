# `.github` — Community Health & Funding Configuration

This repository hosts account-wide default community health files and sponsorship configuration for repositories owned by [@aiwithrajan](https://github.com/aiwithrajan).

### 💖 Sponsorship Configuration

The [`FUNDING.yml`](./FUNDING.yml) file in this repository enables the GitHub **Sponsor** button across all repositories under `@aiwithrajan`:

```yaml
github: [aiwithrajan]
```
